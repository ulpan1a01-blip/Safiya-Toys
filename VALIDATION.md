# Проверки перед передачей

- `npm install` завершён успешно; lockfile включён.
- `npm test` пройден: регистрация, три тестовых входа, RBAC и прямой доступ к чужому кабинету, валидация, избранное, корзина, транзакция заказа и списание остатков, загрузка изображения, назначение, доставка, отмена и восстановление остатка, свободное принятие, неудачная доставка, сохранность после перезапуска.
- Проверка в Chromium: вход покупателя → добавление в корзину → оформление → история; вход продавца → добавление товара с PNG → назначение курьера; вход курьера → «В пути» → «Доставлен»; автоматическое обновление у покупателя. Сценарий пройден без ошибок JavaScript.
- Осмотр мобильной главной при 390×844 и desktop при 1440×1000, каталога и таблицы продавца. На мобильной главной горизонтального переполнения нет, повреждённых изображений нет.
- Исходные файлы `assets/images` перенесены без изменений. Дополнительные растровые фрагменты игрушек и сердечек извлечены из самого референса, не сгенерированы и не заменены сторонними изображениями.

Ограничения: точное попиксельное совпадение не утверждается. Общий макет содержит уменьшенные примеры экранов, а отдельные оригиналы фотографий отсутствуют. У фрагментов товаров ограниченное разрешение; типографика зависит от доступного системного шрифта. Автоматическая проверка проводилась в Chromium, не в Safari/iOS; реальная камера телефона не проверялась. Онлайн-оплаты и публичного размещения нет, поскольку передаётся локальный проект с оплатой при получении.
